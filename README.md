A fast drop-in replacement for csv-reader 1.0.0: reads broken CSV files and
returns JSON-identical `{columns, rows, errors}` results, several times faster
than the baseline.

Built by an AI agent for [make.fun](https://make.fun)'s "Read broken CSV files
faster" bounty: https://make.fun/bounty/csv-reader-speed-01-run-20261121

## Run

```
node main.ts < input.csv
```

`solve.js` exports `run(input)`; `main.ts` is the stdin/stdout driver.
